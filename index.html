Descripción del Proyecto

Este proyecto es una demostración técnica de una interfaz de videojuegos web moderna, utilizando estándares web puros sin dependencias externas.

Tecnologías

  • HTML5 Semántico: Estructura limpia y accesible.
  • CSS3 Moderno: Variables, Flexbox, Grid y Animaciones.
  • Vanilla JavaScript: Lógica de estado y manipulación del DOM.

Estructura

El proyecto sigue una arquitectura de carpetas modular:

PROYECTO/
├── assets/ (Recursos)
├── css/ (Estilos)
├── js/ (Lógica)
├── juegos/ (Módulos independientes)
└── index.html
